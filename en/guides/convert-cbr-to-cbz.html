How to convert CBR comics to CBZ

You have a comic in .cbr and your reader says it can't open it, or some open and others don't. The file isn't broken: it's almost always the compression format, and converting it to .cbz fixes it with no loss of quality.

Updated October 21, 2026 · 7 min read

Short answer
  • Try renaming it first: many .cbr files are really ZIPs. Change the extension to .cbz and open it.
  • If that doesn't work: extract it with 7-Zip (or ZArchiver on your phone), compress the images again as a ZIP and change the extension from .zip to .cbz.
  • The images aren't recompressed: the comic looks exactly the same.

What CBR and CBZ are

A digital comic is nothing special: it's a folder of images (one per page, usually JPG or PNG) packed into an archive with a different extension.

  • CBZ = Comic Book ZIP. The images are in a ZIP.
  • CBR = Comic Book RAR. The images are in a RAR.

The content is identical; only the box changes. Converting one to the other just means taking the images out of one box and putting them in the other, untouched.

Why so many CBR files won't open

RAR is a proprietary format with two versions: the old one (RAR4) and RAR5, which current versions of WinRAR use by default. Many Android apps and libraries can only read the old one, so a CBR made years ago opens while a recent one fails with a vague error like “couldn't read the pages”.

ZIP, on the other hand, opens everywhere with no licences or odd versions. That's why CBZ is the most compatible comic format, and the one we recommend. Balda only opens CBZ: we'd rather tell you to convert a CBR when you import it than let the comic into your library and have it fail later.

Trick 1: try renaming it to .cbz

Plenty of CBR files were made with tools that actually compressed them as ZIP and just named them .cbr. In that case all you need is a new name:

  1. On your computer, turn on file extensions if you can't see them (Windows: File Explorer → View → Show → File name extensions).
  2. Rename My comic.cbr to My comic.cbz. On your phone you can do it in the Files app: long-press the file → Rename.
  3. Open it. If it works, you're done. If it still won't open, it's a real RAR: go to the next step.
🔎

To check without trying: open it in 7-Zip and look at its properties. If it says zip, renaming is enough; if it says Rar or Rar5, you need to convert it.

Convert on Windows with 7-Zip

7-Zip is free, open source, and opens RAR5.

  1. Install 7-Zip.
  2. Right-click the .cbr → 7-Zip → Extract to "My comic\". A folder with the images appears.
  3. Open that folder, select all the images (Ctrl+A), right-click → 7-Zip → Add to archive…
  4. Set Archive format to zip and Compression level to Store: the images are already compressed, so this takes a second. Name it My comic.cbz and click OK.
  5. Check the .cbz opens, then delete the .cbr and the folder if you like.

Convert on Mac or Linux

On a Mac, extract the CBR with The Unarchiver or Keka. On Linux, use your file manager (with unrar or unar installed) or the terminal. Then build the ZIP from the terminal, inside the folder with the images:

cd "My comic"
zip -0 -r -X "../My comic.cbz" .
⚠️

On a Mac, avoid Finder's “Compress”: it adds a hidden __MACOSX folder with files some readers treat as broken pages. If you already did, fix it with zip -d "My comic.cbz" "__MACOSX/*".

Convert right on your phone

No computer handy? ZArchiver (free on Google Play) extracts RAR, including RAR5, and creates ZIPs:

  1. Open ZArchiver and find your .cbr (usually in Download).
  2. Tap it and choose Extract to ./My comic/.
  3. Open the new folder, long-press one image and select them all.
  4. Tap Compress, choose zip as the format and create the archive.
  5. Long-press the resulting .zip → Rename, and change .zip to .cbz.

Then open it in your reader. In Balda: tap “Add” and pick the .cbz, or tap it in ZArchiver and choose “Open with Balda”.

Convert a whole collection at once

If you have a full collection, use a loop instead of doing them one by one. Copy the CBR files to a separate folder first, just in case.

Windows (Command Prompt, inside the folder)

for %f in (*.cbr) do ("C:\Program Files\7-Zip\7z.exe" x "%f" -o"%~nf" && "C:\Program Files\7-Zip\7z.exe" a -tzip -mx0 "%~nf.cbz" ".\%~nf\*")

Mac or Linux (Terminal, inside the folder; needs unar)

for f in *.cbr; do
  d="${f%.cbr}"
  unar -q -D -o "$d" "$f" && (cd "$d" && zip -q -0 -r -X "../$d.cbz" .)
done

Each CBR produces a folder with its images and a CBZ next to it. Once you've checked the CBZs open, you can delete the folders and the CBRs.

Keep the pages in order

Readers sort pages by file name, alphabetically. If the images are named 1.jpg, 2.jpg … 10.jpg, page 10 will appear between pages 1 and 2. Well-made comics use leading zeros (001.jpg, 002.jpg … 010.jpg); if yours doesn't, rename them that way before compressing (on Windows, free tools like PowerRename from PowerToys do it in bulk).

Subfolders inside the ZIP are fine as long as their names also sort in order (Chapter 01, Chapter 02…).
