Why won’t my ebook open on Android?

You have the file, you tap it, and nothing readable happens. Almost every case comes down to a handful of causes. Here is how to recognise each one and what to do.

Updated November 15, 2026 · 6 min read

Short answer

The usual causes are DRM protection, a CBR comic, a damaged or incomplete download, an empty or oversized file, or a format your reader does not support. Read the error message: it normally names the cause. Fixes for each are below.

The messages below are the ones Balda shows, but the causes are the same in any reader.

1. The book has DRM

Message: “This Kindle book is DRM-protected and can't be opened. Only DRM-free Kindle books (AZW3 and MOBI) can be read.”

DRM ties a book to a store account. Books bought from Amazon, and EPUBs that arrive as a small .acsm file, are protected. A reader with no accounts cannot open them. Read them in the store's own app, or look for a DRM-free edition. See how to read MOBI and AZW3 books and how to open EPUB files.

2. It is a CBR comic

Message: “CBR comics cannot be opened. Convert it to CBZ and it will work.”

CBR files use RAR compression, and most of them use a newer RAR variant that Android readers cannot open. Convert the file to CBZ on a computer. See how to convert CBR to CBZ.

3. The file is damaged or incomplete

Messages: “The book could not be read: the file is damaged”, “This EPUB could not be read” or “The PDF could not be opened”.

The most common reason is a download that did not finish, especially on a weak connection. Download the file again, ideally over Wi-Fi, and compare the size with what the site says. If it fails again, try another copy.

4. The file is empty

Message: “That file is empty.”

A file of 0 bytes has nothing in it. It usually means a failed download or a transfer that was interrupted. Get the file again.

5. The file is too large

Message: “The file is over the 200 MB limit.”

Heavily illustrated or scanned books can be enormous. Look for a smaller edition of the same book, such as an EPUB instead of a scan, or compress the file on a computer.

6. The format is not supported

Message: “Unsupported book format.”

Balda reads EPUB, FB2, DRM-free MOBI and AZW3, PDF, TXT, DOCX, ODT and CBZ. Other formats, such as the old .doc Word format, need converting first. Calibre can turn most ebook formats into EPUB. See how to move books from Calibre to Android, and our comparison of ebook formats.

7. The document is password-protected

A Word document protected with a password cannot be read and shows up as damaged. Remove the password in your word processor, save a copy, and import that. See reading Word, ODT and TXT files.

8. It is a ZIP or a different file

Some sites deliver the book inside a .zip. Extract it first and open the book inside. The exception is .fb2.zip, which Balda opens directly. Also check the extension: a web page saved as .html or a file that is really something else is not an ebook, whatever its name.

💡

If the file shows up as a “BIN file” or “PRC file” in Android's picker, that is normal for some ebook formats. Pick it anyway. Balda recognises the format by its name.

Frequently asked questions

The book opens but looks wrong. What now?

Garbled letters usually mean a wrongly encoded file, and a contents list reading “Chapter 1, Chapter 2…” just means the book has no chapter titles. See how to open FB2 files for the details.

Which Balda import errors can I see afterwards?

After importing several books, tap View on the summary message to see each failed book with its reason. See how to add many ebooks at once.

Is it a problem with my phone?

Rarely. If the same file also fails on another device, the file itself is the problem.
